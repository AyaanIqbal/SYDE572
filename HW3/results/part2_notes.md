The 1D view uses petal length. Setosa is clearly separated, while versicolor and virginica overlap. The vertical class rows are display offsets only; the retained feature is the horizontal coordinate.

The 2D view uses petal length and petal width. It isolates setosa and shows broad versicolor and virginica groups with some boundary overlap. The 3D view adds sepal length, but does not completely separate those two species. Of these selected views, the 2D petal plot offers the clearest balance of class structure and readability.
